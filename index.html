02 Factory installation

This operation may erase settings!

The factory image writes from 0x0, including NVS and OTA metadata. The installer also writes LittleFS at 0x310000. This is not a configuration-preserving update.

Web Serial is unavailable. Use desktop Chrome or Edge.HTTPS or localhost is required.

If necessary, hold BOOT while resetting to enter flashing mode. Do not disconnect USB while flashing.

03 Update without erasing settings

For routine updates, use the supported OTA method or PlatformIO with matching firmware.bin and littlefs.bin files. Writing the application at 0x10000 does not guarantee an update to the active OTA slot.
